# Your Name — Personal Portfolio

A responsive, aesthetic personal portfolio with a warm beige, rust, and editorial-inspired design.

## Files

- `index.html` — page structure and portfolio content
- `style.css` — colours, typography, layout, and responsive styling
- `script.js` — mobile navigation and automatic footer year

## How to run

1. Keep all three files in the same folder.
2. Open `index.html` in a browser.
3. Edit the placeholder content to make the portfolio yours.

## Personalise your portfolio

Search in `index.html` and replace:

- `Your Name` with your name
- `YN` with your initials
- `Your City` with your city
- `hello@example.com` with an email address you want to display
- The sample About, Skills, and Project descriptions with your own information

You can also replace the sample project cards with screenshots or links to your real projects.

## Customisation

The main theme colours are defined at the top of `style.css` using CSS variables. Google Fonts are loaded online, so an internet connection is needed for those fonts; the site still works with fallback fonts offline.

Made as an editable starter portfolio.
