# Marwa — Personal Portfolio

A premium, responsive personal portfolio website introducing me, my web development learning journey, current skills and selected practice projects.

## Project structure

```text
Marwa-Portfolio/
├── index.html
├── about.html
├── style.css
├── script.js
└── README.md
```

## Technologies used

- **HTML5:** website structure and content
- **CSS3:** styling, responsive layouts and visual design
- **JavaScript:** mobile navigation and automatic footer year
- **Google Fonts:** Playfair Display and DM Sans

## Website sections

- Home / introduction
- About me
- Skills: HTML, CSS, JavaScript and Bootstrap
- Selected practice projects
- Contact and social links

## Run the website locally

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Keep all files in the same folder so the CSS and JavaScript work correctly.

## Personalise before publishing

In `index.html`, replace:

- `YOUR_EMAIL@example.com` with your real email address.
- The sample GitHub and LinkedIn URLs with your own profile links.
- Add your project repository or live-demo URLs when you publish your projects.

You can also update the About section as your skills and experience grow.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload all files in this folder to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Click **Save** and wait for GitHub Pages to publish your website.
